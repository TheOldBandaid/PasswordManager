# Password Manager
Учебный проект на C#, реализующий менеджер паролей с авторизацией по мастер-паролю. 
Проект создан для изучения подходов по тестированию ПО.

## Возможности
- Авторизация и выход из системы.
- Сохранение, получение, изменение и удаление паролей.
- Проверка авторизации перед выполнением операций.
- Автоматизированные тесты.

## Подходы к разработке и тестированию
- **TDD (Test-Driven Development)** — разработка через тестирование: сначала пишутся тесты, затем реализация, необходимая для их прохождения.
- **ATDD (Acceptance Test-Driven Development)** — разработка через приёмочные тесты, основанные на требованиях к поведению системы.
- **BDD (Behavior-Driven Development)** — разработка через описание поведения системы в виде сценариев на понятном языке.
- **SDD (Specification-Driven Development)** — разработка на основе спецификации. В проекте тестовые сценарии хранятся в JSON и используются для автоматизированной проверки реализации.

## Запуск тестов
```bash
dotnet test PasswordManager.Tests
dotnet test PasswordManager.BDD
dotnet test PasswordManager.SDD
```

Проект предназначен для учебных целей и не является готовым к использованию менеджером паролей: данные хранятся в памяти и не шифруются.
