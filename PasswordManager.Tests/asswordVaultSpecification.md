# Спецификация менеджера паролей

## 1. Спецификация данных

| Поле | Тип данных | Описание | Пример |
|---|---|---|---|
| Мастер-пароль | `string` | Пароль для авторизации пользователя | `master123` |
| Сайт | `string` | Идентификатор записи в хранилище | `example.com` |
| Пароль сайта | `string` | Пароль, сохранённый для сайта | `mySecret123` |

## 2. Спецификация операций

| Операция | Условие | Ожидаемый результат |
|---|---|---|
| Авторизация | Мастер-пароль верный | Доступ разрешён |
| Авторизация | Мастер-пароль неверный | Доступ запрещён |
| Сохранение пароля | Пользователь авторизован | Пароль сохранён |
| Получение пароля | Пользователь авторизован, запись существует | Возвращён сохранённый пароль |
| Получение пароля | Пользователь авторизован, записи нет | Возвращён `null` |
| Обновление пароля | Пользователь авторизован, запись существует | Пароль обновлён |
| Обновление пароля | Пользователь авторизован, записи нет | Выброшено исключение `KeyNotFoundException` |
| Удаление пароля | Пользователь авторизован, запись существует | Возвращено `true`, запись удалена |
| Удаление пароля | Пользователь авторизован, записи нет | Возвращено `false` |
| Любая операция с паролями | Пользователь не авторизован | Выброшено исключение `UnauthorizedAccessException` |
| Выход из системы | Пользователь авторизован | Доступ закрыт до повторной авторизации |

## 3. Ограничения

- Данные хранятся в памяти программы.
- Для доступа к операциям с паролями требуется авторизация.
- Пароли сайтов в текущей реализации не шифруются.
- Спецификация описывает поведение реализованного учебного прототипа.
